v2.1.0 2026-08-19

Enriched fintech-token-ecosystem with current (2026) regulatory, market, and security-practice research: the SEC/CFTC joint interpretive framework, MiCA's machine-readable whitepaper mandate, the US GENIUS Act for stablecoins, FATF Travel Rule enforcement reality, ERC-3643 institutional adoption data, DAO governance/treasury best practices, and 2025–2026 exploit/audit market data.

Changed
  • skills/fintech-token-ecosystem/SKILL.md — Stage 2 gains §2.4 "Design Frameworks & Current Practice (2026)" (stakeholder analysis / incentive-design / participatory co-design frameworks, hybrid inflation-then-burn market pattern, common-failure-modes table). Impacted function: tokenomics design workflow — deeper guidance, stage structure unchanged.
  • Stage 3 — added ERC-4626 to the standards table; added an ERC-3643 institutional-adoption callout ($32B+ RWA tokenized, 180+ jurisdictions, DTCC/Apex/Invesco/Franklin Templeton/Fasanara adopters, ISO standardization underway).
  • Stage 4 — added §4.1 "Governance Model — Current Best Practice" (tiered decision-making, vote delegation, vote-escrow, hybrid weighting, governance minimization) and §4.2 "Treasury — Current Best Practice" (multisig threshold, signer rotation, hardware keys, monitoring, Safe as default tooling).
  • Stage 5 — reworked §5.1 with the March 2026 SEC/CFTC 5-bucket taxonomy and marketing-language-driven Howey analysis, GENIUS Act stablecoin requirements, and MiCA's Dec 2025 XHTML/iXBRL whitepaper mandate; §5.2 now states current FATF Travel Rule enforcement coverage (~73% legislated, ~40% enforced) with named enforcing jurisdictions; §5.3 risk register reordered around access-control failures, oracle manipulation, and bridge compromise as the current leading loss categories, with audit cost bands. Impacted function: compliance & risk analysis workflow — classification guidance, KYC/AML enforcement expectations, and the risk register all updated.
  • Stage 7 — noted the shift from one-time pre-launch audit to continuous post-launch monitoring. Added a closing "A Note on Currency" section.
  • skills/fintech-token-ecosystem/references/token-compliance-reference.md — expanded Regulatory Frameworks section; added "FATF Travel Rule — Enforcement Reality Check (2026)", "Governance Model Quick Reference", "Treasury Multisig Checklist", and "Exploit & Audit Market Data (2025–2026)"; added glossary terms (ve-model, RWA, TWAP); added a dated "Sources & Research Currency" section listing every source consulted.

v2.0.0 2026-08-16

Restructured the repository from a single SAP skill into a multi-skill business analyst set, and added three new domain skills: Fintech token ecosystems, Medtech elderly cognitive health, and AI-collaborative demo building.

Breaking
  • Moved SKILL.md → skills/sap-functional-specs/SKILL.md. Any reference, bookmark, or automation pointing at the old root-level path will break. Impacted function: skill discovery/invocation for sap-functional-specs — the 7-stage workflow content is unchanged, only its file location moved.
  • Moved reference files into skills/sap-functional-specs/references/: sap-transactions-reference.md, example-p2p-fs.md, quick-reference.md.
Added
  • New skill fintech-token-ecosystem (skills/fintech-token-ecosystem/SKILL.md) — 7-stage workflow for token launches and ecosystem management. Covers: business context → tokenomics design (supply, allocation, vesting, incentive loops) → token standard & platform selection → ecosystem component mapping (wallets, exchanges, staking, governance, treasury) → compliance & risk (MiCA, SEC/Howey, KYC/AML) → smart-contract functional spec → TGE launch & lifecycle roadmap.
  • New reference skills/fintech-token-ecosystem/references/token-compliance-reference.md — token standards cheat sheet, regulatory frameworks by jurisdiction, KYC/AML requirement starter set, audit & security checklist.
  • New skill medtech-cognitive-health (skills/medtech-cognitive-health/SKILL.md) — 7-stage workflow for elderly functional-brain/health assessment platforms. Covers: clinical & business context → care pathway mapping (test → score → triage → city-delivered treatment) → assessment model (test battery, scoring, risk stratification, accessibility) → regulatory & data protection (SaMD/MDR/FDA, GDPR/HIPAA, hazard log) → HL7 FHIR interoperability design → formal FS → pilot/rollout roadmap.
  • New reference skills/medtech-cognitive-health/references/healthcare-standards-reference.md — MDR/FDA pathways, GDPR/HIPAA summary, FHIR resource cheat sheet, validated clinical instruments table, hazard log starter set.
  • New skill ai-demo-collaboration (skills/ai-demo-collaboration/SKILL.md) — 6-stage workflow for business analysts building demos in direct collaboration with AI. Covers: demo framing (one-question charter) → persona & journey scoping → AI-buildable spec writing → build-review-refine loop → demo day & structured feedback capture → demo-to-production requirements bridge.
  • New reference skills/ai-demo-collaboration/references/demo-spec-template.md — demo charter, AI-buildable spec template, prompt patterns, demo-ready checklist, feedback capture sheet, demo-to-production gap table.
  • CHANGELOG.md and CHANGELOG.html — this record.
Changed
  • README.md rewritten as an index of all four skills. Impacted function: repo entry point — previously documented only the SAP skill package; now includes a skill overview table, the skills/ directory tree, and how the AI demo skill's output feeds into the domain skills' FS workflows.
